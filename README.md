# Frankly Farhid

Personal portfolio website for Farhid Shaikh — Marketing Expert & Business Planner based in Dubai.

## Stack
- React
- Vite
- Lucide React
- Vercel-ready

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

> Note: this first production-ready wrapper preserves the original Claude JSX prototype. The next refactor should move embedded base64 images and portfolio data into dedicated asset/data files for easier long-term maintenance.
